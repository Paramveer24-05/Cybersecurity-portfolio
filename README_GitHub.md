# Paramveersinh Mahida — Cybersecurity Portfolio

This repository contains the starter website and PDF portfolio for an IIT Kanpur B.Cyber. 2027 aspirant.

## Files
- `index.html` — responsive, single-file portfolio website.
- `Paramveersinh_Mahida_Cybersecurity_Portfolio.pdf` — printable portfolio draft.

## Publish with GitHub Pages
1. Create a new GitHub repository named `paramveersinh-cybersecurity-portfolio` (or another name you prefer).
2. Upload `index.html` and this README. Upload the PDF too if you want it downloadable from the site.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. Copy the published URL into your PDF and portfolio.

## Personalize before publishing
- Add your GitHub profile URL and a professional contact email.
- Add only verified awards, certificates, competition results and completed projects.
- For every project, include source code, test evidence, a short report and limitations.
- Keep security testing inside systems and labs where you have explicit permission.

## Accuracy
The project cards currently say **Planned**. Change them to **Completed** only after you have built, tested and documented the project.
